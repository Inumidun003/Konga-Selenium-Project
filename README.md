Konga Selenium Automation Project

Project Overview

This project focuses on automating the Konga online shopping order flow using Selenium WebDriver.

Objectives

* Automate key steps in the Konga shopping process.
* Verify that website navigation and search functionality work as expected.
* Practice writing and maintaining Selenium automation scripts.

Tools and Technologies

* Selenium WebDriver
* Selenium IDE
* Konga website: https://www.konga.com
* GitHub for version control and project documentation

Test Scenario

The automation script tests the Konga online shopping order flow, including opening the website, searching for products, and navigating product categories.

Project Repository

This repository contains the Selenium IDE test file Konga_Order_flow.side.
